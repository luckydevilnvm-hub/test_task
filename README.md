# Многопоточная библиотека логирования (C++17)

Данный проект представляет собой реализацию динамической библиотеки для записи сообщений в журнал с различными уровнями важности, а также консольное приложение, демонстрирующее её работу в многопоточной среде.

## Реализованные требования
1. **Динамическая библиотека:** Код логгера скомпилирован в отдельный разделяемый объект (`liblogger.so`).
2. **Уровни важности:** Реализованы три уровня: `ERROR`, `WARNING`, `INFO`. Уровень по умолчанию задается при инициализации.
3. **Формат записи:** Каждая строка журнала содержит временную метку, уровень важности и текст сообщения.
4. **Многопоточность:** Приложение использует паттерн "Производитель-Потребитель". Главный поток читает ввод пользователя, а выделенный рабочий поток безопасно записывает данные в файл с использованием `std::mutex` и `std::condition_variable`.
5. **Обработка ввода:** Уровень важности в сообщении пользователя может отсутствовать (в этом случае используется уровень по умолчанию).
6. **Обработка ошибок:** Корректная обработка невозможности открытия файла журнала через исключения.
