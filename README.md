# Многопоточная библиотека логирования (C++17)

Данный проект представляет собой реализацию динамической библиотеки для записи сообщений в журнал с различными уровнями важности, а также консольное приложение, демонстрирующее её работу в многопоточной среде.

## Реализованные требования
1. **Динамическая библиотека:** Код логгера скомпилирован в отдельный разделяемый объект (`liblogger.so`).
2. **Уровни важности:** Реализованы три уровня: `ERROR`, `WARNING`, `INFO`.
3. **Формат записи:** Каждая строка журнала содержит временную метку, уровень важности и текст сообщения.
4. **Многопоточность:** Приложение использует паттерн "Производитель-Потребитель" с потокобезопасной очередью (`std::mutex`, `std::condition_variable`).
5. **Обработка ввода:** Уровень важности в сообщении пользователя может отсутствовать (в этом случае используется уровень по умолчанию). Поддерживается ввод как с квадратными скобками `[ERROR]`, так и без них.
6. **Обработка ошибок:** Корректная обработка невозможности открытия файла журнала через механизмы исключений.

## Сборка проекта
Для компиляции библиотеки и приложения выполните в корневой директории проекта:
```bash
make
```
Для очистки директории от скомпилированных файлов и тестовых логов:
```bash
make clean
```

##  Использование
Приложение принимает два обязательных аргумента командной строки: имя файла журнала и уровень важности по умолчанию.

###  Пример запуска:
```bash
./logger_app my_journal.log INFO
```

### Формат ввода в консоли:
1.С указанием уровня: ERROR Ошибка подключения к базе данных
2.Без указания уровня (будет использован уровень по умолчанию): Пользователь вошел в систему
3.Для корректного завершения работы приложения введите: exit
